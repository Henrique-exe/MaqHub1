MaqHub

E-commerce de Máquinas Pesadas

Desenvolvimento Web Front-End

Autor: Pablo Henrique, Diego Paim, Erik Nogueira, Saymon Galvão

Funcionalidades Implementadas

  • Navegação: Menu responsivo e Slider de destaques.
  • Busca Inteligente: Filtro em tempo real (keyup) integrando produtos estáticos e do localStorage.
  • Carrinho de Compras: Adição, remoção e somatória automática.
  • Sistema de Favoritos: Lista de desejos persistente.

Manipulação do DOM

O Document Object Model foi manipulado para criar uma experiência SPA (Single Page Application) sem recarregamentos constantes.

Aplicações:

  • Injeção de HTML dinâmico para listar produtos (`innerHTML`).
  • Alteração de classes CSS para menus e abas (`classList.toggle`).
  • Criação de elementos para resultados de busca (`document.createElement`).
document.getElementById("cart-items").innerHTML += `<div class="item">...</div>`;

EventListeners

Utilizados para capturar interações do usuário e executar lógicas específicas.

Principais Eventos:

  • 'click': Botões de compra, slider, remover item.
  • 'submit': Validação e envio de formulários (Login/Cadastro).
  • 'keyup': Barra de pesquisa instantânea.
  • 'DOMContentLoaded': Carregamento inicial de dados do Storage.
searchInput.addEventListener('keyup', () => { filtrarProdutos(); });

Validação de Dados

Implementada no JavaScript para garantir integridade antes do armazenamento.

Lógicas aplicadas:

  • Verificação de campos vazios.
  • Confirmação de senha igual à senha digitada.
  • Verificação de e-mail já cadastrado (evita duplicidade).
if (senha !== confirma) { alert("As senhas não conferem!"); return; }

LocalStorage & Persistência

Simulação de Banco de Dados utilizando a memória do navegador.

Fluxo de Dados (JSON):

  • Salvar: `JSON.stringify(array)` converte objetos em texto.
  • Ler: `JSON.parse(texto)` converte texto em objetos.
  • Uso: Sessão de usuário logado, Itens do Carrinho, Lista de Favoritos e Banco de Produtos novos.
const produtos = JSON.parse(localStorage.getItem("produtos")) || [];
